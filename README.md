### 第 8 课：Linux 文件 I/O——目录操作与文件操作函数（更详细）

1. 导入 ★：硬件 IO（引脚 0/1 电平）→ 文件 IO（数据流）；输入/输出是**相对方向**
2. 文件基础回顾：`ls -l` 七字段、UGO 权限与 8421、七种文件类型、硬链接 vs 软链接（`ln` / `ln -s`）
3. 两套 API ★：标准 I/O（`fopen/fread/fwrite/fclose`）vs 文件 I/O（`open/read/write/close`）；系统级头文件 `<sys/stat.h>`、`<unistd.h>`、`<fcntl.h>`
4. 函数三要素与铁律：返回值类型 + 函数名 + 参数；**成功 0 / 失败 −1**；`errno` + `perror` + `strerror`
5. 文件描述符 `fd`（句柄）：0/1/2 被标准流占用，新文件从 3 开始
6. 目录操作 ★：`mkdir`（含 `argc/argv`）、`rmdir`（仅空目录）、`getcwd`、`opendir/readdir/closedir`（扩充）
7. `stat` / `fstat` / `lstat` ★：`struct stat` 成员表、`S_IS*` 类型判断宏
8. 文件操作 ★：`access`（0/1/2/4）、`creat`、`open`（`O_RDONLY/O_WRONLY/O_RDWR/O_CREAT/O_EXCL/O_TRUNC/O_APPEND`）、`close`、`read`、`write`、`lseek`（扩充）、`unlink`
9. 权限陷阱 ★：`umask` 削权——`0777 & ~022 = 0755`
10. 课本例题逐行解析 + 8 个完整可编译程序（mkdir / getcwd / stat / creat / 存在判断 / 读写 / 文件复制 / 目录遍历）
11. 易错点复盘、课堂操作复盘、自测题含答案、函数速查表

### 第 9 课：C 语言时间编程——本地时间与格林威治时间转换（更详细）

1. 课前复习：目录操作（`mkdir/rmdir/getcwd/stat`）与文件操作标准链（`access → creat/open → read/write → close`）
2. 两个时间概念 ★：协调世界时 UTC（格林威治时间）vs 日历时间（1970-01-01 起的秒数，2026 年约 17.9 亿）
3. `time` ★：`time_t time(time_t *tloc)`；参数可传 `NULL`；32 位 `time_t` 的 2038 问题
4. `struct tm` ★：九个成员与取值范围；`tm_year` +1900、`tm_mon` +1、`tm_wday` 0=周日
5. `gmtime` ★：秒 → 格林威治时间；`->` 与 `.` 的区别；输出比本地少 8 小时
6. `localtime` ★：秒 → 本地时间；东八区 UTC+8；**静态缓冲区陷阱**（同时用要先拷贝）
7. `mktime` ★：结构体 → 秒（`localtime` 的逆运算）；会规范化越界字段
8. `gettimeofday` / `settimeofday` ★：`tv_sec` + `tv_usec`（1 秒 = 10⁶ 微秒）、`tz_minuteswest = −480`、夏令时 DST（中国 1986—1991）
9. `asctime` / `ctime` ★：时间 → 字符串；三步 vs 两步；固定格式 `Wed Oct 21 03:47:52 2026`
10. 八个函数总览与转换关系图；本地 ↔ 格林威治的两种转换思路（函数法 / 手减 8 小时）
11. 9 个完整可编译程序；易错点复盘（含课上"1 秒 = 1000 微秒"的口误纠正）、课堂操作复盘、自测题含答案、函数速查表

### 第 10 课：进程控制——fork 与 vfork 进程创建（更详细）

1. 课前复习：第 9 课时间编程八个函数一句话总结
2. 进程引入 ★：任务管理器里的 PID；PID 由系统分配、用户不可干预、**不一定连续**
3. 进程定义 ★：程序关于某数据集合的一次活动，资源分配与调度的基本单元
4. 进程 vs 程序 ★：静态/动态、硬盘/内存、无生命周期/有生命周期
5. 进程分类：用户进程（终端）、守护进程（开机后台，`d` 结尾）、批处理进程（脚本）
6. PCB 进程控制块 ★：双向链表任务队列；`pid`、`state`、`counter`、`timer`、`priority`、`context`
7. 进程创建四步 ★：初始化 PCB → 分配内存 → 入队 → 设状态
8. 六种状态 ★：运行、可中断等待、不可中断等待（保护硬件 I/O）、僵死（PCB 留给父进程读）、停止、销毁；状态转换图
9. 调度与时间片 ★：`counter` 用满/提前完成都收回；单核不是真并行
10. 文件锁（了解）：防多进程同时操作文件；关闭 fd 或进程终止才释放；子进程不继承
11. `system` ★：执行 shell 命令；返回值 −1 / 0 / >0（**教材说"子进程 id"，标准是"终止状态"**）
12. `exec` 函数族 ★：`execl/execlp/execle/execv/execvp/execve`，`l` 列表、`v` 数组、`p` 找 PATH、`e` 环境变量；成功不返回
13. `fork` ★★：`pid_t fork(void)`；**子进程返回 0、父进程返回子 PID、失败 −1**；代码段共享、数据段独立（COW）
14. `vfork` ★：共享地址空间、子先父后、父挂起、必须 `_exit()`
15. `fork` vs `vfork` 对比总表；7 个完整可编译程序（system/execl/execv/fork 基础/fork 例题/fork 树/vfork）
16. 易错点复盘（12 条）、课堂操作复盘、自测题含答案、进程相关函数速查表
