二、课前回顾与环境要求

  • Linux 指令按功能划分为八大类，本课学习其中最高频的两类：用户管理和文件管理。
  • VMware 版本要求：使用老师提供的高版本（约 17.5），不要用更低版本。64 位 Ubuntu 系统由高版本软件制作，低版本无法支持。
  • 终端操作：右键“在终端打开”；放大 Ctrl+Shift+=、缩小 Ctrl+-、清屏 Ctrl+L；指令格式 命令 + 空格 + 操作对象。

三、用户管理命令 ★

3.1 useradd：添加用户

  • 含义：user + add = 添加账户。
  • 格式：sudo useradd 用户名，命令与用户名之间必须有空格。
  • 需要 root 权限：普通用户会提示“只有 root 才能……”，需 sudo。
  • 创建成功后：分配 UID/GID，并在 /home 下生成用户主目录。
  • 验证：ls /home 查看用户目录是否出现。
注意：useradd 不会自动设置密码，必须再用 passwd 用户名 单独设置。

3.2 passwd：设置密码

  • 格式：sudo passwd 用户名。
  • 输入密码不回显是 Linux 安全机制，不是没输入。
  • 密码过短（如 123456）会提示，学习阶段可继续。

3.3 userdel：删除用户

指令作用主目录与文件
userdel 用户名删除账户保留主目录和文件
userdel -r 用户名删除账户及一切连同主目录和文件全部删除
  • -r = remove；完整写法 --remove --home。
  • 删除后 ls /home 中该用户目录不再存在；删除也需 sudo。

3.4 组管理（扩充）

指令作用
groupadd 组名添加组
groupdel 组名删除组
usermod -aG 组名 用户名把用户加入附加组
groups 用户名查看用户所属组

3.5 补充知识（扩充）

  • /etc/passwd：用户基本信息；/etc/shadow：加密密码；/etc/group：组信息。
  • UID 0 是 root；普通用户 UID 一般 ≥ 1000。
  • id 用户名 查看 UID/GID；su - 切换为 root。

四、文件管理命令 ★（重中之重）

老师强调：文件管理是所有命令中的重中之重。命令大多是英文单词缩写，理解单词就好记。

4.1 ls：查看目录内容

  • 含义：list（列表）。
  • 进入目录后执行 ls 查看内容；创建/删除/复制后都要用 ls 验证。
指令作用
ls列出文件名
ls -l 或 ll详细信息：权限、属主、大小、修改时间、文件名
ls -a含隐藏文件（以 . 开头）
ls 目录路径直接查看指定目录，如 ls /tmp
提示：-l 的 l 与数字 1 很像，常用 ll 代替 ls -l，二者等价。

4.2 cd：切换目录

  • 含义：change directory。
  • 类比：上课要“找到主楼 → ES → 0304”，一层一层进入。
指令作用
cd /home/xxx按绝对路径进入
cd ..返回上一级
cd ~回到用户主目录
cd /回到根目录
cd -回到上一次所在目录

4.3 touch：创建文件

  • 格式：sudo touch 文件名，如 touch file1。
  • 批量创建：touch file2 file3 file4 一次搞定。
  • Linux 文件不看后缀：file1、main.c 都是文件，后缀只是约定。
  • 权限不足加 sudo；创建后 ls 验证。
工程应用：批量创建 main.c、key.c、beep.c 等源文件，把不同功能封装成函数独立存放，需要时调用，比 Windows “右键新建”高效。

4.4 mkdir：创建文件夹

  • 含义：make directory。
  • 格式：sudo mkdir 目录名；可批量：mkdir dir1 dir2 dir3。
  • ls 中目录通常显示蓝色，方便区分。
扩充：mkdir -p a/b/c 可一次性创建多级目录。

4.5 cp：复制 ★（本课难点）

  • 含义：copy，相当于 Windows 的 Ctrl+C / Ctrl+V。
  • 格式：cp 源 目标（前源后目标）。
操作指令说明
复制文件cp 文件 目标目录不需要加 -r
复制目录cp -r 目录 目标目录必须加 -r（递归）
  • 不加 -r 复制目录会报错（未指定 -r / omitting directory）。
  • 复制后新文件时间戳是复制时刻，不是源文件创建时间。
  • 示例：sudo cp /home/DIR1/file1 /home/DIR2/；sudo cp -r /home/DIR1 /home/DIR2/。

4.6 pwd：查看当前路径

含义：print working directory。迷路时执行 pwd，立即知道当前在哪个目录。

4.7 绝对路径 vs 相对路径 ★（教材第 5 章 / 137 页）

类型定义特点示例
绝对路径从根目录 / 开始的完整路径唯一、任何时候可用cd /home/DIR1/file1
相对路径相对当前目录的路径简洁、依赖当前位置cd ..、cd DIR3

五、效率技巧（扩充）

技巧说明
Tab 自动补齐输入首字母按 Tab：唯一匹配则自动补全；多个匹配则补公共前缀
history显示安装以来执行过的全部命令，运维可追溯操作记录
上下方向键调出上一条/下一条命令
Ctrl+L / Ctrl+C清屏 / 中断当前命令
man 命令查看命令手册
扩充：真实服务器上删除文件、改配置都有 history 记录，出问题可追溯，运维操作要谨慎。

六、易错点复盘 ★

  1. useradd 忘记加 sudo → 权限不足。
  2. useradd 后忘记 passwd 设置密码 → 无法登录。
  3. userdel 与 userdel -r 混淆（-r 很危险，慎用）。
  4. 复制目录忘记加 -r → 报错失败。
  5. 命令与对象之间忘加空格 → 系统不认识。
  6. 绝对路径与相对路径混用 → 找不到文件，先 pwd。
  7. touch（文件）与 mkdir（目录）用混。
  8. ll 就是 ls -l，不是另一个命令。

七、课堂操作复盘（标准流程）

  1. 创建用户：sudo useradd aa → sudo passwd aa → ls /home 验证。
  2. 删除用户（保留主目录）：sudo userdel aa。
  3. 删除用户（连主目录）：sudo userdel -r aa → ls /home 验证。
  4. 创建文件：sudo touch file1，批量 touch file2 file3 → ls 验证。
  5. 创建目录：sudo mkdir dir1 dir2 dir3 → ls 验证（蓝色为目录）。
  6. 复制文件：sudo cp /home/DIR1/file1 /home/DIR2/ → 验证。
  7. 复制目录：sudo cp -r /home/DIR1 /home/DIR2/ → 进入目录验证。
  8. 查看路径/返回：pwd、cd ..、cd /。

八、复习自测题（含答案）

基础题

  1. useradd 与 adduser 有什么区别？
  2. userdel 与 userdel -r 有什么区别？
  3. ls、ls -l（ll）、ls -a 各显示什么？
  4. touch 与 mkdir 的区别？
  5. cp 复制文件与复制目录有什么不同？
  6. 绝对路径与相对路径的区别？各举一例。
  7. pwd 的作用是什么？
  8. Tab 键在终端中有什么作用？
  9. Linux 中文件名后缀重要吗？
  10. 如何查看系统历史命令？

参考答案

  1. useradd 是底层命令，需 passwd 单独设密码；adduser 是交互式命令，会引导设置。
  2. userdel 保留主目录；userdel -r 连同主目录和文件全部删除。
  3. ls 只列文件名；ll/ls -l 显示详细属性；ls -a 额外显示隐藏文件。
  4. touch 创建文件；mkdir 创建文件夹（目录）。
  5. 复制文件不加参数；复制目录必须加 -r（递归）。
  6. 绝对路径从 / 开始、唯一（/home/DIR1/file1）；相对路径相对当前目录（cd ..）。
  7. 显示当前所在目录的完整路径。
  8. 命令/文件名的自动补齐，提高输入效率。
  9. 不重要，Linux 不靠后缀区分文件类型，后缀只是约定。
  10. 执行 history 查看历史命令记录。
